# MADS-box Examples

This directory contains example workflows demonstrating the use of GENE-FAM to identify and characterise MADS-box genes using both GenBank and RefSeq genome assemblies.

## MADS_GenBank_example

In this example, GENE-FAM is run on an unannotated GenBank *Cannabis sativa* genome assembly from the Abacus strain (`GCA_025232715.1`) to identify and characterise MADS-box genes.

## MADS_RefSeq_example

In this example, GENE-FAM is run on *Malus domestica* (apple) and *Arabidopsis thaliana* to mine MADS-box genes. As these are RefSeq genomes with associated annotation files available, the required genome and annotation files can be downloaded automatically using GENE-FAM.
